一、四轴（顶层分类骨架）

A1 分类轴

横向分类轴：诸子十家 → 部类 → 流派 → 体裁 → 版本。回答「这部子书属于哪一家、哪一类」。相关类 21 个。

A2 思想轴

纵向内容轴：道体 → 范畴 → 命题 → 典籍 → 篇章 → 句读。回答「在讲什么思想、义理结构怎样」。相关类 22 个。

A3 人物轴

人物传承轴：诸子 → 弟子 → 注家 → 学者 → 传人。回答「谁立说、谁传承、谁注解」。相关类 14 个。

A4 事件轴

事件缘起轴：问道 → 著述 → 争鸣 → 整理 → 刻印 → 流传。回答「何时何地何缘著书立说」。相关类 11 个。

二、七层（抽象层级）

L0

元模型层

描述本体所用的元语言：轴、层、类、属性、关系、实例。类 7 个。

L1

道体本体层

诸子学最顶层的形而上学核心概念（道、仁、法、性、天、理、气…）。类 1 个。

L2

义理范畴层

诸子核心思想分析框架（阴阳、名实、天人、义利、王霸、礼法、心性…）。类 1 个。

L3

宗派流派层

诸子十二家学派及其思想体系，以及流派传承、学术宗旨、核心主张。类 8 个。

L4

文本载体层

子藏典籍、部类、篇章结构（典籍→篇→章→句）、版本与异本、注疏。类 22 个。

L5

人物传承层

诸子、弟子、注疏家、历代研究者、学派传人。类 6 个。

L6

信仰文化外延层

民间化诸子人物、制度技艺外延元素：如孔子为文宣王、老子为道教始祖、法家思想对历代制度的影响、兵家谋略的应用等。类 3 个。

诸子流派判教对比

儒家 · 五常教化

核心概念

仁、义、礼、智、信、忠恕、中庸、教化、正名

代表人物

孔子、孟子、荀子、董仲舒、朱熹

核心典籍

《论语》《孟子》《荀子》《春秋繁露》

核心主张

以仁为核心，以礼为规范，主张德治教化、修己安人；孟子主性善、倡仁政，荀子主性恶、重礼法，后世发展为经学与理学。

道家 · 道法自然

核心概念

道、自然、无为、虚静、齐物、逍遥、柔弱胜刚强

代表人物

老子、庄子、列子、文子、淮南子

核心典籍

《道德经》《庄子》《列子》《文子》《淮南子》

核心主张

以道为本体，主张道法自然、无为而治；老庄追求精神逍遥，黄老主张君无为而臣有为，对中国艺术、医学、政治影响深远。

法家 · 刑名法术

核心概念

法、术、势、刑名、赏罚、耕战、中央集权

代表人物

商鞅、申不害、慎到、韩非、李斯

核心典籍

《商君书》《韩非子》《慎子》《申子》

核心主张

主张以法治国、信赏必罚，兼用术（驾驭臣下）、势（君主权威）；韩非集法家大成，为秦统一提供理论基础，后世阳儒阴法。

墨家 · 兼爱非攻

核心概念

兼爱、非攻、尚贤、尚同、天志、明鬼、节用、节葬

代表人物

墨子、禽滑厘、后期墨家

核心典籍

《墨子》（含墨辩逻辑、光学、力学内容）

核心主张

主张无差别的兼爱，反对战争；重视逻辑与科技，提倡尚贤使能、节俭薄葬，是先秦带有平民色彩的学派，汉后中绝。

兵家 · 权谋形势

核心概念

道、天、地、将、法、奇正、虚实、形势、权谋

代表人物

孙武、司马穰苴、吴起、孙膑、尉缭

核心典籍

《孙子兵法》《吴子》《司马法》《孙膑兵法》《六韬》

核心主张

分为兵权谋、兵形势、兵阴阳、兵技巧四类，以《孙子兵法》为代表，主张不战而屈人之兵、知彼知己、因敌制胜，影响遍及世界军事与商业领域。

名家 · 名实之辩

核心概念

名实、白马非马、坚白同异、合同异、离坚白

代表人物

邓析、惠施、公孙龙、尹文子

核心典籍

《公孙龙子》《邓析子》《尹文子》《惠子》（佚）

核心主张

专注于名实关系与逻辑思辨，惠施主张"合同异"（强调事物同一性），公孙龙主张"离坚白""白马非马"（强调概念差异性），是中国古代的逻辑学传统。
