子藏本体论 问题诊断 总体架构 核心通用本体 领域扩展本体 四轴映射 建模示例 实施路径 参考项目

子 藏 本 体 论

模块化构建方案 · 1+N 分层设计

子藏在四部分类中最为庞杂：诸子思想、兵法谋略、刑名律法、农耕桑麻、医药针灸、历算天文、卜筮风水、琴棋书画、类书汇编、笔记小说……
不能像佛藏、儒藏那样用单一教义模型硬套。本方案参考 CIDOC CRM、BIBFRAME、TCMLS、FOAF、SKOS 等国际成熟本体， 采用「1个核心通用本体 + N个领域扩展本体」的模块化架构——核心层统一复用，领域层按需插入，各子类拥有专属语义模型。

一、问题诊断：子藏为什么不能用一套模型？

佛藏有统一的教义结构（佛→法→僧→经→律→论），儒藏有统一的经学结构（经→传→注→疏→义理），但子藏从内容性质看至少可分为 11 种本质不同的知识形态，用一套通用模型必然削足适履：

①
哲学思想型

儒/道/墨/名/阴阳等诸子典籍。核心是「道-范畴-命题-章句」义理结构，需要概念树、命题网络和师承关系。

②
谋略战阵型

兵书、纵横家言。核心是「战争-方略-阵法-权谋-形势」，有目标、敌我、虚实、奇正等博弈论结构。

③
制度刑名型

法家、官制、政书。核心是「法-术-势-刑-赏」，围绕律令条文、刑名等级、治理术建模。

④
农业技术型

农家、茶经、花谱、兽医。核心是「农时-土壤-作物-农具-水利」，是工艺知识，需要工序、材料、时令参数。

⑤
医药诊疗型

医家、本草、针灸、房中。核心是「理-法-方-药-证-穴-经络」，TCMLS已有成熟框架，直接扩展。

⑥
历算推步型

算法、天文、历法。核心是「数-算-术-器-历-星」，需要数学公式、算法步骤、天文观测记录。

⑦
术数占卜型

卜筮、命理、相术、风水、择吉。核心是「命-卜-相-堪舆-择吉」，有符号系统（干支/八卦/五行）、推演规则、吉凶判词。

⑧
艺术技法型

书谱、画论、琴学、棋经、印谱、砚史、酒谱。核心是「书/画/琴/棋/印/器」，围绕技法、品鉴、器物、流派。

⑨
类书汇编型

《艺文类聚》《太平御览》《册府元龟》等。核心是「部-类-目-事-文」，是百科知识库，重在知识分类和引文溯源。

⑩
笔记小说型

笔记、志怪、传奇、话本、演义。核心是「人物-故事-场景-意象」，是叙事性文本，需要情节、角色、地点、事件建模。

⑪
博综杂家型

《吕氏春秋》《淮南子》《论衡》等，兼儒墨、合名法，核心是跨学派主题关联。

🎯 核心原则：同层复用，异层扩展

所有子书共享的通用维度（书名、作者、版本、卷次、成书时代、文本篇章、引书关系、人物基本信息）放在核心本体，复用成熟国际标准；
不同类型独有的知识结构（哲学命题、兵法方略、方药证穴、卜筮推演、故事情节）放在各领域扩展本体，按需插拔。
模块之间通过「导入（owl:imports）+ 桥接公理」连接，单一领域更新不影响其他模块。

二、总体架构：1+N 五层本体栈

▎五层本体栈（Ontology Stack）

L5
应用层
应用视图本体（Application View）按需构建

面向具体应用场景的视图组装，如「诸子思想地图」「兵家谋略检索」「中医药知识问答」「小说人物关系」。通过SPARQL视图/命名图从下层抽取，不新增顶层类。

L4
领域层
领域扩展本体 N 个（Domain Extension Ontology）领域特化

诸子本体 / 兵家本体 / 法家本体 / 农家本体 / 医家本体 / 历算本体 / 术数本体 / 艺术本体 / 类书本体 / 小说本体 / 杂家本体——各子类独有类与属性。

L3
核心层
子藏核心本体（ZCore）统一复用

所有子书共通的语义骨架：文献结构（作品/版本/篇章/条文）、人物（诸子/注家/弟子）、事件（著述/争鸣/校勘/刻印）、时空、概念词表。

L2
对齐层
国际标准本体对齐（Alignment）外部引用

owl:equivalentClass / rdfs:subClassOf 映射至：CIDOC CRM（事件）、BIBFRAME（书目）、FOAF（人物）、SKOS（概念）、Dublin Core（元数据）、Schema.org、PROV-O（溯源）、TIME（时间）、GeoSPARQL（地理）。

L1
元层
元本体层（Meta）逻辑基础

OWL 2 RL / RDFS 元语：owl:Class, owl:ObjectProperty, owl:DatatypeProperty, rdfs:subClassOf, owl:Restriction，本体版本信息与模块声明。

三、核心通用本体 ZCore（所有子书共享）

ZCore 定义 6 个顶级类，共约 40 个核心类、30+通用属性，所有领域本体的类都继承自这些顶类，并与国际标准本体对齐。

3.1 六大顶级类（Top Classes）

顶类中文名说明对齐国际标准
zc:Work典籍作品抽象层面的著作概念，如《道德经》《孙子兵法》（不涉及具体版本）bf:Work / frbr:Work
zc:Expression文本表达作品的具体文字形态，如王弼注本、河上公注本、白文bf:Expression / frbr:Expression
zc:Manifestation版本载体具体刻本/印本/抄本，如宋刻本、四部丛刊本、点校本bf:Manifestation / frbr:Manifestation
zc:Person人物诸子、注家、弟子、刻者、序跋作者等所有历史人物foaf:Person / E21 Person
zc:Event事件著述、问对、争鸣、校书、刻印、奏进、作序等事件，事件中心建模E5 Event / prov:Activity
zc:Concept概念通用概念词，学派、术语、名物、制度等，用SKOS词表组织skos:Concept / E55 Type

3.2 文献结构（Work → Item 五层，对齐 BIBFRAME/FRBR）

zc:Work（作品）

一部书的抽象概念。属性：题名、别名、所属子类、学派归属、成书年代、作者。

zc:Expression（表达）

白文/注本/校本/译本等文字形态。属性：注释者、注本体例（注/疏/集解/正义）、文字差异。

zc:Manifestation（版本）

某一刻印/抄写版本。属性：版本年代、刻者、刻地、行款、避讳、藏书印、存佚。

zc:Item（单件）

具体某一册藏本（藏馆+索书号）。属性：收藏机构、存卷情况、品相、数字化URL。

zc:TextComponent（文本组件）

内部结构：篇/卷/章/节/句/注文/疏文/音义/校记。属性：卷次、序号、原文文本。

3.3 核心对象属性（通用关系）

属性域→值说明
zc:authorOf / zc:authoredByPerson ↔ Work作者关系（含托名、撰、注、集解、编、续）
zc:discipleOf / zc:teacherOfPerson ↔ Person师承关系，师承链
zc:contemporaryOfPerson ↔ Person同时代交游关系（如孔子问礼于老子）
zc:cites / zc:citedByWork ↔ Work引书关系（互见/化用/驳斥）
zc:commentaryOnExpression → Work某注本是对哪部书的注释
zc:hasPart / zc:partOfWork/TextComponent 递归篇章包含关系，支持任意深度卷-篇-章-句
zc:hasVersion / zc:versionOfWork ↔ Manifestation版本关系
zc:participatedInPerson → Event人物参与某事件
zc:occurredAt / zc:occurredDuringEvent → Place / TimeSpan事件时空
zc:producedEvent → Work某事件（著述/刻印）产出某书
zc:schoolAffiliationPerson/Work → Concept学派归属（儒家/道家/法家…）
skos:broader / skos:narrowerConcept ↔ Concept概念上下位

四、11 个领域扩展本体（Domain Ontology）

每个领域本体 extends ZCore，新增领域专属类与属性，并建立跨域桥接关系。下表逐一给出各领域的核心类、核心关系与建模范式。

① 诸子哲学本体（ZhuziOnto）

思想·义理型
核心类（8个）
  • zz:Daoti（道体）：最高形上概念，如「道」「仁」「天」「无」「法」「理」
  • zz:Category（范畴）：义理基本范畴，如「阴阳」「名实」「义利」「王霸」「礼法」
  • zz:Proposition（命题）：可判定真假的哲学语句，如「性善」「白马非马」「仁者爱人」
  • zz:Argument（论证）：命题的论证结构（比喻、类比、推理、寓言）
  • zz:School（学派）：儒家/道家/墨家/法家/名家/阴阳家…
  • zz:Chapter（篇章）→ zc:TextComponent
  • zz:Dialogue（问答）：语录体中师徒/君臣问对，作为事件
  • zz:Debate（争鸣）：学派间辩论事件，如孟辟杨墨、儒法之争、名墨辩
核心关系
  • zz:arguesFor / zz:arguesAgainst：命题支持/反驳
  • zz:daotiOf：范畴归属某道体（阴阳属于道）
  • zz:propounds：人物提出某命题
  • zz:dialogueBetween：问答参与人
  • zz:debatesWith：学派间辩论关系
  • zz:inheritsFrom：学派传承（庄子→玄学→禅宗→理学）
建模范式：四轴（分类/思想/人物/事件）×七层（道体→范畴→命题→论证→章句→人物→事件）——即佛学本体直接适配。

② 兵家谋略本体（BingjiaOnto）

谋略·战阵型
核心类（9个）
  • zb:War（战争/战役）：历史战例，作为事件
  • zb:Strategy（战略/方略）：全胜、伐谋、伐交、伐兵、攻城…
  • zb:Tactic（战术/阵法）：奇正、虚实、分合、形势；八阵、六花阵…
  • zb:MilitaryForce（兵力）：将、卒、车、骑、弩、粮
  • zb:Terrain（地形）：通/挂/支/隘/险/远（《孙子·地形》）
  • zb:Commander（将帅）→ zc:Person
  • zb:Weapon（兵器）：戈/矛/弩/车/舰/火攻器具
  • zb:Disposition（形/势）：兵力部署状态
  • zb:Deception（诡道/权谋）：能而示之不能、用而示之不用…
核心关系
  • zb:commands：将→军；zb:defeats：军→军
  • zb:applies：战例→战略/战术
  • zb:suitableTerrain / zb:contraindicatedTerrain：战术适用/禁忌地形
  • zb:usesWeapon / zb:usesForce
  • zb:counters：战术克制（奇胜正、虚实相生）
建模范式：以「战例」为中心事件，连接双方将帅、兵力、地形、所用方略，形成「方略—战例—结果」三元组，支持案例检索和谋略推演。

③ 法家刑名本体（FajiaOnto）

制度·治理型
核心类（7个）
  • zf:Law（法/律令）：成文法条、律、令、制、诏
  • zf:Method（术）：君主驭臣之术（循名责实、潜御群臣）
  • zf:Power（势/位势）：权威、势位、赏罚二柄
  • zf:Punishment（刑/罚）：刑罚等级，刑名对应
  • zf:Reward（赏/爵禄）
  • zf:OfficialPosition（官职/名位）：名实体系中的「名」
  • zf:GovernanceEvent（治理事件）：变法（商鞅变法）、行法、刑赏
核心关系
  • zf:prescribesPunishment / zf:prescribesReward：法条对应刑赏
  • zf:matches（刑名相应）：官职名→职责实
  • zf:implementedIn：法→变法事件
  • zf:integrates（法/术/势结合）：韩非集大成关系
建模范式：以「法-术-势」三角为骨架，刑罚与官职做名实匹配，连接历史变法事件。

④ 农家工艺本体（NongjiaOnto）

技术·工艺型
核心类（8个）
  • zn:Crop（作物）：稻/麦/黍/稷/桑/麻/茶/果蔬
  • zn:Soil（土壤）：土类分级（《禹贡》九州土壤）
  • zn:FarmTool（农具）：耒/耜/犁/锄/水车/龙骨车
  • zn:Season（农时/节气）：二十四节气、月令
  • zn:Irrigation（水利）：渠/堰/陂/塘/井
  • zn:AgriculturalProcess（农事工序）：耕/耙/播/耘/收/藏
  • zn:Livestock（家畜/兽医）
  • zn:Pest（虫害/灾害）
核心关系
  • zn:suitableSeason / zn:suitableSoil：作物适宜时令/土壤
  • zn:usedInProcess：农具→工序
  • zn:processSequence：工序先后关系
  • zn:prevents：防治→虫害
建模范式：工艺知识——「作物×时令×土壤×工序×农具」多维度矩阵，每道工序作为事件连接时序。

⑤ 医家诊疗本体（YijiaOnto / TCM）

医学·诊疗型
核心类（扩展 TCMLS）
  • zy:YinYangWuXing（阴阳五行）→ zz:Category：桥接诸子哲学
  • zy:Zheng（证/证候）：辨证结果，如太阳证、脾虚证
  • zy:Disease（病）：伤寒、温病、杂病
  • zy:Symptom（症/症状）
  • zy:TherapeuticMethod（治法）：汗/吐/下/和/温/清/消/补八法
  • zy:Prescription（方/方剂）：经方、时方
  • zy:Herb（药/本草）：药性（四气五味归经）
  • zy:Meridian（经络）/zy:Acupoint（穴位）
  • zy:Case（医案）→ zc:Event：诊疗事件
核心关系（理-法-方-药闭环）
  • zy:manifestedAs：病→症；zy:differentiatedAs：症→证
  • zy:treatedBy：证→法→方→药
  • zy:composedOf：方→药（君臣佐使）
  • zy:entersMeridian：药→经络
  • zy:recordedIn：医案→典籍条文
建模范式：直接复用 TCMLS（12万概念、127万语义关系）已建立的96种语义类型，通过 owl:imports 桥接阴阳五行到诸子本体，形成「理→法→方→药→案」五段闭环。

⑥ 历算推步本体（LisuanOnto）

数学·天文型
核心类（8个）
  • zs:Number（数）：整数、分数、负数、开方
  • zs:Algorithm（术/算法）：今有术、盈不足、方程、勾股
  • zs:Problem（问/题目）：典籍中的算题
  • zs:Answer（答）/zs:Method（术曰解答）
  • zs:Instrument（算器）：算筹、算盘、浑天仪、日晷
  • zs:CelestialBody（天体）：日/月/五星/二十八宿
  • zs:CalendarSystem（历法）：太初历、大衍历、授时历
  • zs:Ephemeris（星表/推步记录）
核心关系
  • zs:solvedBy：题目→算法
  • zs:usesInstrument：算法→算器
  • zs:predicts：历法→天象位置
  • zs:basedOn：后历→前历（如《授时历》基于《大衍历》）
建模范式：「问题→算法→答案→应用（天文/历法）」四步结构，算法步骤可形式化为规则，支持数学史和古天文复推。

⑦ 术数占卜本体（ShushuOnto）

符号·推演型
核心类（10个）
  • zsh:SymbolSystem（符号系统）：干支、八卦、五行、六十四卦、九宫
  • zsh:DivinationMethod（占法）：龟卜/蓍筮/六爻/四柱/奇门/六壬/太乙/堪舆/相术/择吉
  • zsh:Hexagram（卦）/zsh:Trigram（三爻卦）
  • zsh:GanZhi（干支）/zsh:WuXing（五行）→ zy:YinYangWuXing
  • zsh:Diagram（图/式盘）：河图、洛书、奇门式盘
  • zsh:DivinationQuery（占问事项）
  • zsh:DivinationResult（占断/判词/吉凶）
  • zsh:FengshuiSite（风水位点）：龙/砂/水/穴/向
  • zsh:PhysiognomyFeature（相术特征）：面相/骨相/手相
核心关系
  • zsh:generates / zsh:overcomes：五行生克
  • zsh:correspondsTo：干支↔五行↔方位↔季节（万物类象）
  • zsh:derivedFrom：卦→爻→卦辞→爻辞
  • zsh:predicts：占法+问项→判词
建模范式：以「符号系统+推演规则+万物类象表」为核心，五行生克是推理引擎的图遍历基础。

⑧ 艺术技法本体（YishuOnto）

审美·技艺型
核心类（9个）
  • za:Artwork（作品/艺术品）：法帖、名画、琴曲、棋谱
  • za:Technique（技法）：书法用笔/画法皴法/琴指法/棋定势
  • za:Style（风格/流派）：院体/文人画/吴门/浙派
  • za:MaterialTool（材料工具）：笔/墨/纸/砚/琴弦/棋子
  • za:Appreciation（品鉴/品评）：谢赫六法、书品、画品
  • za:Artist（艺术家）→ zc:Person
  • za:Treatise（论著/谱录）→ zc:Work
  • za:Artifact（器物）：名砚、名琴、古器
  • za:Composition（章法/布局）
核心关系
  • za:createdBy / za:paintedBy / za:calligraphedBy
  • za:usesTechnique / za:inStyleOf
  • za:critiquedBy：品评→艺术品
  • za:passedThrough：鉴藏流传（收藏印序列→事件）
建模范式：「艺术家→作品→技法→风格→品鉴→器物」六维，重在审美评价和流派传承。

⑨ 类书汇编本体（LeishuOnto）

百科·汇编型
核心类（6个）
  • zl:Section（部）：天/地/人/事/物…
  • zl:Category（类）：部下分类（如天部：天、日、月、星、云…）
  • zl:Entry（条目/事类）
  • zl:Quotation（引文）：每条下所引之书，注明出处
  • zl:SourceWork（引书）→ zc:Work
  • zl:Rhythm（韵）：《佩文韵府》韵字系联
核心关系
  • zl:hasSection / zl:hasCategory / zl:hasEntry 层级结构
  • zl:quotesFrom：引文→原书（zc:cites 的细化）
  • zl:arrangedBy：类书编排方式（类序/韵序）
建模范式：类书本质是「古代知识库」，以部-类-目-事-引文五层树组织，引文溯源是其核心价值。

⑩ 笔记小说本体（BijiXiaoshuoOnto）

叙事·文学型
核心类（9个）
  • zx:Story（故事/条目）：笔记中每一条独立叙事
  • zx:Character（角色）：人物、鬼狐、神仙、异人
  • zx:Scene（场景/地点）
  • zx:PlotEvent（情节事件）：故事内事件（CIDOC E5）
  • zx:Motif（母题/意象）：离魂、化蝶、狐仙、梦游、遇仙
  • zx:Genre（体裁/类型）：志怪/传奇/笔记/话本/演义
  • zx:Theme（主题）
  • zx:Narrator（叙述者）
  • zx:Source（传闻来源/出处）
核心关系
  • zx:featuresCharacter：故事→角色
  • zx:hasPlotSequence：情节先后
  • zx:employsMotif：故事→母题（母题类型学，可建SKOS词表）
  • zx:influencedBy / zx:adaptedFrom：故事间改编、因袭
建模范式：以「故事」为中心叙事单元，采用CIDOC CRM事件中心模型，角色-场景-情节-母题四要素，支持母题检索和故事类型学研究（类似汤普森《民间故事母题索引》）。

⑪ 杂家博综本体（ZajiaOnto）

跨域·综合型
核心类（3个）
  • zzaj:Theme（主题）：跨学派论旨，如「治道」「养生」「君道」
  • zzaj:EclecticClaim（兼综主张）：综合多家的具体论点
  • zzaj:Synthesis（综合体系）：如《吕氏春秋》十二纪体系、《淮南子》宇宙论
核心关系
  • zzaj:synthesizes：综合→多家命题/范畴
  • zzaj:borrowsFrom：借自哪一学派
  • zzaj:organizesBy：组织原则（时令、天地人、治道分类）
建模范式：杂家本身不定义新的底类，而是桥接本体——通过 owl:imports 引入诸子、兵家、农家等多个本体，用「综合」关系把跨学派命题关联起来。

八、参考的本体论项目

CIDOC CRM (ISO 21127)

文化遗产领域国际标准本体，81核心类+事件中心建模。故宫据此扩展CRM-ACA用于中国文物，何琳等用于先秦典籍本体。我们复用E5事件、E39行动者、E53地点、E52时间。

BIBFRAME 2.0/3.0

美国国会图书馆发起的关联数据书目模型，Hub-Work-Instance-Item四层。广东省立中山图书馆已实现CNMARC→BIBFRAME转换。我们的文献结构层直接对齐。

FRBR / FRBRoo

IFLA书目关系模型，Work-Expression-Manifestation-Item四层，FRBRoo扩展CIDOC CRM。与BIBFRAME互为补充。

TCMLS（中医药学语言系统）

中国中医科学院构建，12万概念、30万术语、127万语义关系，96种语义类型+58种语义关系。医家本体直接扩展复用。

FOAF / SKOS / Dublin Core

W3C通用本体：FOAF描述人物社交网络，SKOS组织概念词表（叙词表），DC描述元数据。ZCore直接imports。

Schema.org / PROV-O / TIME

Schema.org通用描述；PROV-O溯源本体描述著述刻印的来源链；OWL-Time时间本体处理历史纪年。

佛学本体（yejinlei/Buddhist）

您已构建的四轴×七层架构（A1分类/A2思想/A3人物/A4事件 × L0元模型~L6文化外延），直接作为诸子哲学本体的模板。

儒藏本体（yejinlei/Confucian-Canon）

书籍归放架构，经-传-注-疏-义理五级解经层次，作为诸子和医家典籍层级参考。

上古先秦典籍本体（何琳等）

基于CIDOC CRM构建先秦典籍本体，规则+CRF抽取《左传》实例，F值93%/82%，提供了可复用的方法论。

上海图书馆古籍循证本体

夏翠娟等构建，面向古籍循证需求，BIBFRAME+CIDOC CRM融合，用于上海图书馆古籍联合目录。

Palantir Ontology

工业级本体建模思想：对象-属性-关系-动态本体，强调模块化可演化，可供大规模工程参考。

Ontology Design Patterns (ODP)

本体设计模式库，提供事件、参与者、时序、部分-整体等通用建模模板，避免重复造轮子。

📌 总结：子藏本体论的本质

子藏不是一本书、也不是一个宗派，而是一个古代知识世界——它同时包含哲学、宗教、军事、法律、科技、医学、艺术、文学、百科……
因此子藏本体论不是一个本体，而是一个本体生态系统（Ontology Ecosystem）：
核心层像《艺文类聚》的分类目录，给出共同骨架；
领域层像各子类的专门之学，各有各的逻辑；
桥接层像杂家「兼儒墨、合名法」的智慧，让不同类型的知识在跨域命题处互通。

这正是中华知识体系的本来面貌——「同归而殊途，一致而百虑」（《周易·系辞》）。
