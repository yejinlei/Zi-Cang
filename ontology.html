本体设计原则

子藏本体论设计四原则：
① 模块化分层：核心本体 ZCore 共享骨架 + 11个领域扩展本体（诸子/兵家/法家/农家/医家/历算/术数/艺术/类书/笔记小说/杂家），通过 owl:imports 桥接；
② 四轴正交：分类轴（部类·流派·体裁·版本）× 思想轴（道体·范畴·命题·章句）× 人物轴（诸子·弟子·注家·学者）× 事件轴（著述·争鸣·整理·流传）；
③ 七层抽象：L0元模型→L1道体→L2义理范畴→L3宗派流派→L4文本载体→L5人物传承→L6文化外延；
④ 文献可溯：每条三元组都可追溯到原始文献原文，保留多版本异文，不做擅断。

核心类树（owl:Class）

## ZCore 核心顶级类（所有子书共享）
zc:Work — 著作（思想作品抽象层）
zc:Expression — 文本表达（具体版本的文本）
zc:Manifestation — 版本载体（刻本/抄本/印本）
zc:Item — 具体藏本（单件实物）
zc:Person — 人物（诸子/弟子/注家/学者）
zc:Event — 事件（著述/争鸣/校书/刻印）
zc:Concept — 概念（道体/范畴/命题）
zc:School — 学派流派（九流十家）

## 文献结构类
zc:Chapter — 篇章
zc:Passage — 段落/章句
zc:Annotation — 注疏（注/疏/传/笺/正义）
zc:Citation — 引文（引书出处）

## 思想类

zc:Proposition — 命题（哲学论断）
zc:Argument — 论证（说理链条）

示例三元组

## 《庄子·逍遥游》本体片段
zc:book_zhuangzi a zc:Work ;
  rdfs:label "庄子"@zh-Hans ;
  zc:alternateName "南华真经"@zh-Hans ;
  zc:belongsToSchool zc:school_dao ;
  zc:author zc:person_zhuangzhou ;
  zc:hasChapter zc:ch_xiaoyaoyou .

## 庄子人物
zc:person_zhuangzhou a zc:Person ;
  rdfs:label "庄周"@zh-Hans ;
  zc:zihao "庄子"@zh-Hans ;
  zc:dynasty "战国"@zh-Hans ;
  zc:nativePlace "宋国蒙"@zh-Hans ;
  zc:discipleOf zc:person_laozi ;
  zc:followsDoctrineOf zc:daoti_dao .

## "道"概念
zc:daoti_dao a zc:Daoti ;
  rdfs:label "道"@zh-Hans ;
  skos:definition "形上本体，万物之所由，先天地生，独立而不改，周行而不殆"@zh-Hans ;
  zc:discussedIn zc:book_laozi, zc:book_zhuangzi .

## 学术关系
zc:person_xunzi zc:criticizes zc:person_mengzi . // 荀子驳孟子性善论
zc:person_hanfei zc:followsDoctrineOf zc:person_xunzi . // 韩非师事荀子

七层抽象层级（L0→L6）

L0

元模型层

本体元语言定义：owl:Class / rdf:Property / owl:ObjectProperty / owl:DatatypeProperty / owl:Restriction，定义所有上层类的建模规则。

L1

道体本体层

36个形上核心概念：道、德、仁、义、礼、法、术、势、性、心、天、命、理、气、无极、太极、阴阳、五行等，是诸子思想的终极根据。

L2

义理范畴层

84个思想分析范畴：名实、天人、义利、王霸、礼法、知行、心性、理气、体用、本末、动静、常变、形上形下等，是概念之间的关系框架。

L3

宗派流派层

九流十家十二学派：儒家、道家、法家、墨家、兵家、名家、农家、杂家、阴阳家、纵横家、小说家、医家，含师承源流与学派分化。

L4

文本载体层

1463部子藏典籍结构：书→篇→章→句→注→疏→版本，含殆知阁全文本数据，支持逐句定位与引文溯源。

L5

人物传承层

189位诸子、弟子、注家、学者的人物关系网：师承、宗述、引述、驳斥、评议五类学术关系，含朝代、籍贯、字号、代表作。

L6

文化外延层

民间化诸子人物、制度技艺、信仰民俗、成语典故、文学演绎等文化外延元素，连接精英思想与大众文化。

SPARQL 查询端点

本项目提供可下载的 Turtle (.ttl) 本体文件，可在 Apache Jena Fuseki、GraphDB、Blazegraph 等任意 SPARQL 端点中加载后查询。以下为示例查询模板。
# 查询：某一流派的所有代表人物及其代表作
PREFIX zc: <https://yejinlei.github.io/Zi-Cang/ontology/zicang#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?personName ?bookName WHERE {
  ?person a zc:Person ;
    rdfs:label ?personName ;
    zc:belongsToSchool zc:school_dao ;
    zc:authorOf ?book .
  ?book rdfs:label ?bookName .
}

# 查询：某一概念在哪些典籍中被讨论
SELECT ?bookName WHERE {
  ?concept a zc:Daoti ;
    rdfs:label "道"@zh-Hans ;
    zc:discussedIn ?book .
  ?book rdfs:label ?bookName .
}

# 查询：某人物的学术师承链（传递）
SELECT ?teacherName WHERE {
  ?student rdfs:label "韩非"@zh-Hans .
  ?student zc:discipleOf+ ?teacher .
  ?teacher rdfs:label ?teacherName .
}
