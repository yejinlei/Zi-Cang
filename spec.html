本體規範總綱
子藏本體論（ZCore v2.0）之 TBox 層完整規範：24 個類、42 個物件屬性、28 個資料屬性，並說明「1+N」模組化架構與七層抽象。
一、類（Classes）
TBox 層之核心概念分類，含 FRBR 式「作品—表現—載體」三層與校勘學異文對象。
識別符中文英文父類定義實例數
二、物件屬性（Object Properties）
連結兩個類實例之語義關係，如「作者」「駁斥」「含步驟」。
識別符中文定義域值域
三、資料屬性（Data Properties）
類實例所帶之字面值屬性，如「字數」「生年」「校記」。
識別符中文適用類值類型
四、「1+N」模組化架構
各子類知識形態本質不同，故以 ZCore 為核心，各領域擴展本體透過 owl:imports 橋接。
1ZCore 核心本體：定義作品、篇章、人物、學派、概念五大基本類與通用屬性，為所有擴展之共同基底。
N領域擴展本體（11）：道家、儒家、墨家、法家、名家、兵家、農家、醫家、術數、雜家、（諸子）百科，各自定義專有類與屬性。
↗橋接規則：醫家 import 諸子（氣、陰陽）；術數 import 醫家（五行）；雜家 import 多本體；兵家 import 法家（刑賞）。
⇄對外映射：與 CIDOC CRM、BIBFRAME、FOAF、SKOS、Dublin Core 建立 owl:equivalentClass / equivalentProperty 映射。
五、七層抽象
由字面到思想的七級抽象，決定知識在圖譜中的粒度。
六、TBox / ABox 分層
TBox（本頁）：類與屬性之定義層，即 schema，說明「有哪些類、有哪些關係」。
ABox（RDF 圖譜頁）：實例斷言層，即具體事實，如「《韓非子》作者是韓非」「性善論 對立於 性惡論」。
序列化：以 RDF/Turtle 為主，頁面內以 JSON-LD 內嵌供機器讀取。
